# OpenPocketBase SDK 0.1.1

PocketBase integration for Unreal Engine 5.8 with Blueprint and native C++ APIs.

## Documentation and support

- Documentation: https://github.com/ishtms/OpenPocketBaseSDK
- Support: https://github.com/ishtms/OpenPocketBaseSDK/issues

## Requirements

- Unreal Engine 5.8
- Windows 64-bit or macOS
- Data Validation, an Unreal Engine plugin included with the engine and enabled automatically
- A separately hosted PocketBase server supplied and configured by the user

## Third-party software statement

This package contains no third-party code or libraries and does not vendor, statically link, or dynamically link PocketBase software. It communicates with the user-configured PocketBase server through its public HTTP and SSE APIs using Unreal Engine's built-in networking and JSON modules. The plugin sends no data to its publisher.
